# Imagens dos produtos

Crie uma pasta por peça, usando o mesmo `slug` cadastrado em `assets/js/products.js`:

```text
assets/images/produtos/
  nome-da-peca/
    principal.webp
    detalhe-01.webp
    detalhe-02.webp
```

Use `principal.webp` como imagem principal. As imagens `detalhe-01.webp`, `detalhe-02.webp` e seguintes são opcionais e entram na galeria na ordem em que forem listadas no produto.

Prefira fotos oficiais, bem iluminadas, recortadas na vertical e otimizadas para a web. Não use imagens de referência como se fossem fotos reais do produto. Se usar outro formato ou nome, atualize os caminhos no cadastro da peça.
